# 50 on GIGs website

## Run locally
1. Extract the ZIP file.
2. Open the `50-on-gigs-website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
- Replace the sample Unsplash photos with real 50 on GIGs photos.
- Add a real venue walkthrough/event video in the video section.
- Confirm the exact street address and update the location section / Google Maps search.
- Replace the social media `#` links with the venue's actual Instagram, TikTok and Facebook URLs.
- Update event dates and lineup details.
- The logo is cropped from the supplied poster; replace it with the original transparent logo file if available.

The page uses HTML, CSS and a small inline JavaScript snippet for the mobile navigation and current year. Google Fonts and sample photos require an internet connection.
